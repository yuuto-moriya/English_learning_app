# 要件定義 — Eliza Patina（旧名 Michi・Tetsu English）

オーナー（yuuto-moriya）が最初に出した要件と、開発中に決めた事項をまとめたものです。
**機能の追加・変更や UI 改善の前に必ず読み、ここに書かれた方針から外れる場合はオーナーに確認してください。**
決定事項が変わったら、このファイルも更新します。

## 1. 目的

英語の **学習** と **翻訳** をひとつで扱える統合アプリ。
初学者〜上級者が、日常で必要な英語の学びから実務での実践まで、段階的に身につけられることを目指す。
主な利用者は、日本人の英語学習者。一般・ビジネス・IT が中心で、鉄道保線・設備管理（EAM）は付帯のコース（もともとの利用者の分野）。画面の説明・入力例・既定の動作は一般向けにし、保線は選んだときだけ出す。

## 5. 守ること（変更時の制約）

- 表示文言は **日本語**。英語は学習対象としてのみ表示する
- 学習データ（`src/data/vocab/*.json`）は手で編集しない。`data-src/` を直して `npm run data:build`
- 保線用語の定義は規格本文の転載をしない（要約・意訳）。出典タグを付ける
- API キーやトークンをコード・`vercel.json`・リポジトリに書かない
- 学習データを端末の外へ送らない（翻訳・発音評価で送るのは入力文と録音だけ。読み上げで送るのは読み上げる英文だけ。同時通訳・音声入力で送るのは話した音声だけ）
- iPhone の Safari と、ホーム画面に追加した状態（standalone）の両方で動くこと
- 入力欄の文字は 16px 以上（iOS の自動ズーム防止）
